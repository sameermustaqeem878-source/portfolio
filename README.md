## Run Locally

No build step is needed.

```bash
git clone https://github.com/sameermustaqeem878-source/portfolio.git
cd portfolio
```

Then open `index.html` in your browser, or serve it locally:

```bash
npx serve .
# or
python -m http.server 8000
```

## Deployment

The site is deployed on Vercel. Every push to `main` redeploys automatically.
